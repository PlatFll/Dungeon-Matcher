# Art & PixelLab Rules for this Task

## A. Current style authority

Read before generation:
- `Docs/ArtDirection/Dungeon_Matcher_Art_Direction.txt`
- `Docs/ArtDirection/Golden_Reference_Register.md`

Primary rendering standard:
- **Rattlebones**

Supporting references should be chosen from the current approved/proposed golden/supporting register as appropriate.

## B. What “match the style” means here

New/generated sprites must have:
- crisp native pixels;
- dark outlines;
- readable face and main prop/equipment;
- broad connected material planes;
- restrained shading;
- economical detail;
- silhouette clarity at gameplay scale;
- whimsical nostalgic fantasy tone.

Do not produce glossy HD-pixel or painterly sprites.
Do not over-render fur, cloth, metal or anatomy.

## C. Minotaur-specific art notes

Preserve concept flavor but make him clearly **larger/more imposing than the orcs**.
Possible ways:
- taller torso mass;
- bigger shoulders/chest;
- stronger horn silhouette;
- heavier hoof/leg base;
- broader arm swing.

He should still fit within the game’s combat framing without breaking UI readability.

## D. Kobold-specific art notes

Avoid “cowboy kobold.”
Instead, think:
- dungeon trick-shooter,
- scrappy scavenger marksman,
- eccentric blind/half-blind denizen,
- compact reptilian body with strong personality.

One revolver only.
The revolver can have fantasy craftsmanship or scavenged-dungeon detailing.

## E. Required workflow

For generated stills / redesigns:
1. gather actual golden-reference images;
2. pass them through supported PixelLab style/reference fields;
3. generate still candidates;
4. select the best fit;
5. if needed, perform direct cleanup/editing;
6. only then continue to animation / integration.

If a chosen endpoint cannot accept the required real image references,
use another supported endpoint or report the limitation.
Do not silently fall back to text-only style prompts.

## F. Allowed regeneration scope

The user explicitly allows regeneration/revision of **the new playable character sprites** if needed.
Do not casually regenerate unrelated enemy casts during this task.

## G. Review artifacts

Produce:
- candidate still comparison boards;
- final selected stills;
- native-size views;
- style-fit notes.

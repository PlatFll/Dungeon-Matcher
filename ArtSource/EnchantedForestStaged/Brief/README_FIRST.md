# Enchanted Forest Zone Rebuild Pack

This pack is for Astra to rebuild the **magical forest / enchanted living woodland zone** in staged production using **PixelLab** (for asset generation) and **LibreSprite** (for cleanup, palette alignment, and animation prep).

## Primary goal
Rebuild the forest zone so it matches the attached reference image closely in **layout, mood, and asset identity**, while staying consistent with the game's established pixel-art language:
- crisp native pixel art
- readable silhouettes
- controlled shading (no noisy over-detail)
- palette consistency with the current game
- assets that feel alive and magical

## Important constraints
- Keep the **bottom HUD / potion slot / bomb slot / resonance panel / settings buttons style unified** with the current game family.
- Build the **forest-specific top area, side decorations, board surroundings, and atmospheric magical elements** for this zone.
- Use the included reference image as the main target.
- Build assets **in stages** so PixelLab stays focused.
- After every PixelLab result, clean in LibreSprite as needed.

## Included
- The main reference image
- A starter prompt
- Branch/rule guidance
- Stage-by-stage production order
- One prompt file per stage
- Validation checklist
- Review stop points

Start with `00_STARTER_PROMPT.txt`, then follow `03_STAGE_ORDER.md` and the prompt files in `/prompts`.

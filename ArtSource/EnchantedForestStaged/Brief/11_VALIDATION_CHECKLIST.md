# Validation Checklist

Every stage must pass these checks before approval:

## Crispness
- Native pixel scale is sharp
- No blur or anti-aliased edges
- No accidental soft filtering

## Style match
- Feels like the same family as the dungeon zone and Rattlebones/gem art
- Controlled shading, no muddy over-rendering
- Palette stays in the game's established range

## Theme match
- Feels like an enchanted living forest
- Decorative choices support the theme
- Nothing feels random or goofy

## Structural quality
- Tiles align cleanly
- Decorative overlays sit correctly
- No visible seams unless intentional
- No broken/torn pixels

## Production quality
- Modular where intended
- Layering is clear
- Animation-ready pieces are separated when needed

## Assembly quality
- No clutter conflicts with gameplay readability
- Enemy lane remains readable
- Board remains readable
- Bottom HUD remains unified with global game UI

STAGE 4 — BOARD OUTER FRAME

Goal:
Build the forest board surround so it feels more alive and premium than the current version.

Use:
- `reference/enchanted_forest_match_3_battle_reference.png`

Instructions:
1. Generate the board outer frame as a clean wooden/organic structure.
2. The frame should be surrounded and enriched with leaves, curling vines, branch forms, and natural growth.
3. It should still preserve strong board readability.
4. The design should avoid random glued-on clutter. Make the decorations feel grown from the frame.
5. Add visual richness especially along side edges and corners.
6. Think in modular parts when possible:
   - top edge
   - bottom edge
   - left edge
   - right edge
   - corners
   - leaf/vine overlays
7. Clean in LibreSprite:
   - remove fuzzy generated texture
   - tighten linework
   - unify palette
   - make modular seams clean

Important:
This stage should solve the user's complaint that the board frame felt goofy or randomly decorated. It should feel intentional and natural.

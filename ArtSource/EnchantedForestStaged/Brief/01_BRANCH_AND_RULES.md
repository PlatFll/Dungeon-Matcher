# Branch and Rules

## Branch
Create and work on:
`feature/forest-zone-staged-rebuild`

## Rules
1. No merge.
2. No destructive edits to unrelated zones.
3. Preserve current shared bottom HUD/button family unless a file in this pack explicitly asks for forest-zone-only decorative context around it.
4. Forest assets must be modular when practical.
5. Every asset must pass a crispness and readability check.
6. Every PixelLab output must be inspected and cleaned in LibreSprite before being considered approved.
7. Never let PixelLab improvise random clutter on the board frame. Decorations must be intentional and natural.
8. Avoid goofy/random props that do not support the magical forest theme.
9. Prefer leaf clusters, curling vines, branches, roots, mushrooms, hanging lanterns, rune carvings, glowing wisps, bark trim, and subtle flowers.
10. The environment should feel like a **living enchanted woodland shrine / clearing**, not a plain wooden frame with random ornaments.

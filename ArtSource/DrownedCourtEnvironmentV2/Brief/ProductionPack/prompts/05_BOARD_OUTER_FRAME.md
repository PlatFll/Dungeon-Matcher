## Build actual modular outer frame, not board art
- Stone corner pieces, side rails, top/bottom repeatable stone beams, small connecting plates and optional restrained shell/coral ornamental marks.
- Preserve board 8x8 cell count, tile pitch and pixel edges; keep dark standard grid cells & six gem families unchanged.
- Include safe layering sockets where environmental coral/kelp outside the frame can attach later.

### PixelLab description A — corner
> Ancient submerged blue-turquoise stone frame corner for a 2D match-3 8x8 board, structural L-shaped carved blue-green stone blocks with dark chiseled seams, muted aqua top-left rim highlight and small dull silver brace, no hanging trinkets, no oversized decorative coral. Designed as independent corner module with clean inner dark edge; pixel-perfect 2D art, transparent surrounding background, no gems or grid.

### PixelLab description B — rail
> Repeatable straight masonry board border rail in ancient underwater royal palace style, deep teal-blue stone blocks and small metal joints, calm dark edges, readable vertical or horizontal clean repeating module, minimal chips and no random coral stickers. Exact compatible seam ends. Native pixel art game asset, no full frame and no UI text.

## Avoid
Generic blue-tinted Dungeon purple rails, coral dominating the inside edge, off-grid stretches, canted bars, copied baked gems and wonky corners.

## Validation
Render whole empty 8x8 board with actual locked cell source; all 4 corners separate; check the full rectangular outer profile and true 1x seam edges. Stop.

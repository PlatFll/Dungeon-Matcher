# Shared UI Lock

These elements must remain visually consistent across all 3 zones.

## Keep same across all zones
1. Guide button style
2. Settings / gear button style
3. Potion holder style
4. Bomb holder style
5. Center action / ability panel style
6. Bottom HUD overall construction
7. Shared pixel-text treatment / spacing rules where practical

## Visual language
Use the already approved family seen in the mockups:
- pale gray / silver frame tops
- darker inner stone/metal framing
- purple jewel / purple-energy accents where relevant
- chunky readable construction
- premium crisp pixel-art finish

## What can vary slightly
Minor context-sensitive shading/placement may vary only if necessary for scene integration, but the player should immediately read these as the same global UI system across zones.

## Explicit reminder
Do not make the bottom HUD look different in every zone.
The user wants these shared.

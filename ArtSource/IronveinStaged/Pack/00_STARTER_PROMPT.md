# Ironvein Excavation — Starter Prompt for Astra

Use the attached Ironvein Excavation concept image only as a **composition target and thematic guide**.
Do **not** try to recreate the whole screen in one generation.
Do **not** rely on direct image-to-image generation as the main workflow.
This zone must be built using a **text-description-driven PixelLab workflow**, asset family by asset family, stage by stage, with focused prompts.

## Mission
Build the **Ironvein Excavation** zone so it reaches the same level of quality and cohesion as the approved Dungeon and Magical Forest zones.
The current weak result happened because too much was attempted at once. Fix that by slowing down, splitting the work into stages, and giving each stage focused PixelLab time.

## Non-negotiable workflow rules
- Work on a dedicated branch.
- Complete the stages in the provided order.
- Treat **each stage prompt file as its own focused task**.
- Do **not** skip ahead.
- Do **not** generate the entire screen in one shot.
- Use PixelLab to generate **small, modular asset families** from text descriptions.
- After generating assets, clean them up, recolor them, and align them to our existing palette/shading guide.
- Assemble incrementally in Unity.
- Validate after each stage.
- Continue until **all stages are complete**.
- **Stop only before merge**. Do not merge.

## Core aesthetic goal
Ironvein Excavation should feel like:
- a dwarven mining cavern
- sturdy and geometric
- heavy stone + iron + timber
- warm orange lantern/fire glow against deep cool cave shadows
- rails, ore, carved supports, mine structures, excavation machinery hints
- readable and crisp, not blurry
- polished pixel-art game UI, matching the same family as Dungeon + Magical Forest

## What must stay globally consistent
- game layout
- bottom HUD structure
- general UI logic
- button readability
- existing gem style
- Rattlebones style
- overall resolution discipline and crispness

## What should be zone-specific
- top battle background art
- character portrait frame treatment
- board frame treatment
- side structures around the board
- bottom environmental dressing
- mining props and ambient details

## Final stop condition
Do not stop after a partial scene.
Do not stop after a few generated parts.
Work through all stage prompt files in this pack.
Only stop when:
1. all stage assets are built and cleaned,
2. the scene is assembled in Unity,
3. validation passes,
4. everything is ready for review,
5. and no merge has been made.

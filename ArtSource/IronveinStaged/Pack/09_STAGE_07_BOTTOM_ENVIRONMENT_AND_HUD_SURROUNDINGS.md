# Stage 07 — Bottom Environment and HUD Surroundings

## Goal
Make the lower part of the scene feel built into the excavation zone while keeping the shared HUD readable.

## Desired feel
- the bottom HUD still belongs to the global game
- but the surrounding environment should clearly feel like Ironvein Excavation
- the zone should wrap around the bottom area with mining support structures and grounded environment details

## Generate these asset families
1. lower stone wall / rock base modules
2. timber braces / ledges
3. small ore cart corners / crate stacks
4. rubble and rock piles
5. lower lantern placements
6. small ground support accents

## PixelLab prompt guidance
### Prompt A — Lower environment wall/base kit
"Create modular pixel-art lower-environment stone base assets for a dwarven mine match-3 zone. Dark cave rock, sturdy dwarven masonry, readable cluster shading, clean edges, polished game asset quality."

### Prompt B — Lower braces and supports
"Create modular pixel-art timber braces and small structural supports for the lower part of a dwarven cave game UI scene. Rugged, sturdy, clean pixel readability, warm brown wood, subtle wear."

### Prompt C — Lower rubble / crate dressing
"Create small pixel-art rubble piles, ore crates, and rock dressing assets for the bottom area of a dwarven mine zone. Compact, readable, game-ready, decorative but restrained."

## Rule
The shared bottom HUD remains structurally the same.
This stage dresses the area around it.

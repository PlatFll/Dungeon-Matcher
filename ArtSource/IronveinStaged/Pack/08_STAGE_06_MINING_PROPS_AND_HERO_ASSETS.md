# Stage 06 — Mining Props and Hero Assets

## Goal
Generate the hero props that sell the zone fantasy.

## Generate these prop families
1. mine carts
2. ore crates / boxes
3. barrels
4. pickaxes / mining tools
5. rope bundles / gear piles
6. hanging lantern variants
7. ore piles / crystal deposits
8. wheel / excavation machinery accents

## PixelLab prompt guidance
### Prompt A — Mining props core kit
"Create a modular pixel-art dwarven mining prop set for a fantasy excavation cavern. Include mine carts, ore crates, barrels, and mining tools. Warm lantern-lit atmosphere, crisp readable pixel clusters, polished game-ready asset quality."

### Prompt B — Machinery accents
"Create small pixel-art dwarven mining machinery accents for a fantasy cave zone: wheel mechanisms, ore lifts, reinforced mine hardware. Keep them readable, compact, and suitable as background/side props in a polished match-3 game."

### Prompt C — Ore piles / deposits
"Create small pixel-art ore deposits and mined crystal piles for a dwarven excavation zone. Warm glowing ore, dark stone context, crisp cluster shading, readable and decorative."

## Rule
Use these selectively. This stage is for hero props and atmosphere, not clutter spam.

# Stage 02 — Top HUD Background Kit

## Goal
Build the top battle-area environment using PixelLab from text prompts only.

## Generate these asset families separately
1. carved cave wall tiles / rock wall modules
2. dwarven tunnel / stone arch / mine doorway pieces
3. timber support beams and braces
4. lantern props and hanging variants
5. rail / cart-track modules
6. ore glow accents / crystal clusters
7. mining equipment silhouettes (subtle)
8. cavern depth background shapes

## PixelLab prompt guidance
Generate each family independently.
Keep outputs modular and game-ready.

### Prompt A — Cave wall modules
"Create modular pixel-art dwarven cave wall tiles for a fantasy match-3 combat zone. Deep cool rock, sturdy cut-stone logic, readable pixel clusters, clean edges, dark mining cavern atmosphere, subtle warm torch influence, no blur, no painterly rendering, polished game-asset quality."

### Prompt B — Stone arch / mine opening
"Create modular pixel-art stone arch and mine tunnel entrance assets for a dwarven excavation zone. Heavy carved masonry, sturdy dwarven construction, geometric forms, readable pixel clusters, clean crisp sprite treatment, subtle warm cave lighting."

### Prompt C — Timber supports
"Create modular pixel-art mining support beams and wooden braces for a dwarven cave. Heavy timber, structural and rugged, reinforced feeling, warm brown wood with subtle wear, crisp cluster shading, polished game-ready pixel art."

### Prompt D — Lantern kit
"Create a small modular pixel-art set of hanging mining lanterns for a dwarven excavation zone. Warm glowing lantern light, dark metal housings, readable silhouette, crisp pixel clusters, polished fantasy game asset style."

### Prompt E — Rail / track kit
"Create modular pixel-art mine track assets for a dwarven excavation zone. Wooden ties, iron rails, readable perspective for a fantasy game scene, clean pixel readability, no blur, no noise spam."

### Prompt F — Ore accents
"Create small pixel-art ore seams and glowing excavation crystal accents embedded in cave rock. Warm amber/orange glow, subtle but readable, polished game asset style, clean pixel-art clusters."

## Integration rule
Assemble the top HUD background only after the asset families are individually approved.

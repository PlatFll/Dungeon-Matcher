# Stage 05 — Side Pillars and Supports

## Goal
Create the environmental side structures around the board and scene so the zone feels architecturally complete.

## Desired feel
- structural pillars
- reinforced masonry
- suspended chains
- lantern hooks
- excavated stonework
- restrained dwarven atmosphere

## Generate these asset families
1. side pillar modules
2. chain variants
3. wall bracket / lantern mount variants
4. masonry inset panels / skull-or-rune plaque variants if appropriate
5. side beam transitions into the board region

## PixelLab prompt guidance
### Prompt A — Stone pillar kit
"Create modular pixel-art dwarven stone support pillars for a mine excavation zone. Geometric carved masonry, sturdy vertical structure, readable cluster shading, subtle wear, polished fantasy game asset style."

### Prompt B — Chains and brackets
"Create a small modular pixel-art set of iron chains, hanging chain links, lantern hooks, and wall brackets for a dwarven cave mine zone. Clean silhouettes, crisp clusters, readable and game-ready."

### Prompt C — Side support accents
"Create pixel-art architectural support details for a dwarven excavation zone: reinforced stone inserts, metal braces, and compact ornamental mining motifs. Keep it readable, crisp, and restrained."

## Rule
Keep the top already-working UI layout stable.
Add support and atmosphere without clutter.

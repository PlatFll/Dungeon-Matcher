# Stage 04 — Board Frame Kit

## Goal
Build a board frame that feels purpose-built for a dwarven mine/excavation zone.

## Desired feel
- heavy and strong
- cut stone with iron reinforcement
- angular dwarven craftsmanship
- crisp pixel edges
- not too busy
- enough visual character to stand beside the forest and dungeon zones

## Generate these pieces
1. board corner modules
2. top edge modules
3. bottom edge modules
4. left/right edge modules
5. side structural inserts
6. small glow/ore accent insets if needed

## PixelLab prompt guidance
### Prompt A — Main board frame kit
"Create a modular pixel-art match-3 board frame for a dwarven mining cavern zone. Heavy cut stone, iron reinforcements, angular dwarven craftsmanship, subtle ore inset accents, crisp readable pixel-art clusters, polished fantasy mobile game UI style."

### Prompt B — Optional inset ore accents
"Create small pixel-art decorative inset crystals or ore capsules for a dwarven excavation board frame. Warm amber/orange light, compact and readable, decorative but restrained, polished pixel game asset style."

## Rule
The frame must support readability of gems first.
Do not overpower the board contents.

# Stage 03 — Portrait Frame Kit

## Goal
Create a zone-specific portrait frame that stays structurally compatible with the game UI but visually fits Ironvein Excavation.

## Desired feel
- stone-and-iron dwarven construction
- sturdy reinforced corners
- heavy but clean
- slightly industrial / mining-adjacent
- not too ornate

## Generate these pieces
1. outer corner modules
2. vertical side modules
3. top beam module
4. bottom beam module
5. inner backing treatment for the portrait background
6. small accent pieces if needed (rivets, inset ore bolts, metal plates)

## PixelLab prompt guidance
### Prompt A — Frame structure kit
"Create a modular pixel-art player portrait frame for a dwarven mine zone in a fantasy match-3 game. Heavy stone-and-iron construction, reinforced corners, riveted metal, readable pixel-art clusters, crisp clean structure, compatible with an existing mobile game UI."

### Prompt B — Portrait backing
"Create a pixel-art portrait frame interior backing for a dwarven cave zone. Dark stone or cave-wall backing, subtle readable texture, restrained detail, clean crisp clusters, suitable behind a character portrait."

## Important rule
Do not redesign the gameplay layout.
Only redesign the art treatment of the portrait frame so it belongs to the zone.

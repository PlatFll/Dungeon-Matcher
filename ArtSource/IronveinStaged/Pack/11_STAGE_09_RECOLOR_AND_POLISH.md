# Stage 09 — Recolor and Polish

## Goal
Bring all generated assets into the established game style.

## Required cleanup pass
- simplify any muddy shading
- fix off-style cluster patterns
- recolor to match the zone palette
- unify light behavior
- remove blurry or low-confidence generated texture
- sharpen silhouettes if needed
- make sure metal, wood, rock, and glow each read distinctly

## Quality standard
The final scene should feel:
- crisp
- intentional
- stylized
- game-ready
- visually aligned with Dungeon and Magical Forest

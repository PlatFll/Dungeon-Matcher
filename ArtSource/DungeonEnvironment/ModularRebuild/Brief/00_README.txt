Dungeon Matcher — Dungeon Battle Scene Extraction Pack

Purpose
- Help Astra rebuild the shown dungeon battle scene as modular assets instead of as one flat image.
- Excludes character and gem production assets. The screenshot is used only as a structural and style reference.

What is included
1) full scene reference
2) annotated scene map
3) extracted crops for key UI / frame / background elements
4) JSON manifest with crop coordinates
5) Astra handoff prompt

Important notes
- The screenshot is at displayed scale, not guaranteed native 1x source scale.
- Some extracted crops are clean enough to serve as direct shape references.
- Some extracted crops (especially floor samples and long borders) should be treated as rebuild references, not copy-paste finals.
- The goal is to reconstruct the scene from modular parts in native pixel art while preserving the approved visual language.

Suggested rebuild order
1. Top UI: wave plaque, guide button, settings button.
2. Left portrait panel: wall background tile, outer frame, banner, affinity holder, HP bar.
3. Battle backdrop: door arch, torch sconces, banners, barrels, bones, floor tiles.
4. Gem board frame: corners, top/bottom strips, side strips.
5. Bottom HUD: energy bar, center ability panel, side item buttons, resonance strip.
6. Final scene assembly and alignment pass.

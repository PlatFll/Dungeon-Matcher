# Asset production order

## Stage 1 — Forest structure foundation
Build the forest top battle background foundation:
- far background forest depth
- midground battleground strip for enemies
- simplified scenic backdrop
- enemy standing ground
- basic environmental framing context

## Stage 2 — Forest player frame
Build the player portrait frame variant:
- wooden frame construction
- antler/banner identity
- inner backing treatment
- restrained leaf/vine dressing
- readable gem slot compatibility

## Stage 3 — Forest board frame and side dressing
Build the board frame variant:
- wood/vine board shell
- side supports / carved posts
- limited decorative mushrooms / flowers / runes / hanging lanterns
- keep board readability first

## Stage 4 — Secondary props and polish
Generate or refine extra forest props as needed:
- lantern variants
- mushrooms
- flowers
- signpost or rune carving
- roots/vines
- small foreground flourishes

## Stage 5 — Unity assembly and validation
Assemble zone in Unity, validate, compare against references, and stop for review.

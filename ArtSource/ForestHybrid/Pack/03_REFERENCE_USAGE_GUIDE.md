# Reference usage guide

## Reference A: `references/01_forest_mockup_reference.png`
Use this for:
- overall forest mood
- material language for wooden frames
- vine and leaf treatment
- magical forest backdrop ideas
- lantern placement ideas
- forest board frame identity
- player frame theme identity

Do not copy its density 1:1.
Simplify it for game-native readability.

## Reference B: `references/02_current_dungeon_zone_reference.png`
Use this for:
- current production quality bar
- scene proportions
- combat readability
- board readability
- how much detail is acceptable in a real zone
- how clean the enemy area should remain
- how strong or restrained surrounding decoration should be

## Hybrid interpretation rule
Astra should think:
- “Build the forest zone with the discipline and readability of Reference B.”
- “Style the forest zone with the material identity and mood of Reference A.”

## Shared UI rule
Shared bottom HUD and other unified global controls should visually remain the same family across all zones.

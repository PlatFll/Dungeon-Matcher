# Stage 3 — Forest board frame and side dressing

## Objective
Build the Magical Forest board frame and surrounding side dressing.

## Direction
Use the forest mockup for the wood/vine board frame language, but simplify the amount of tiny foliage and keep gem readability first.

## Build targets
- board outer frame
- vertical side support structures
- top/bottom trims if needed
- restrained decorative accents: mushrooms, flowers, vines, carved wood knots, runes, hanging lanterns

## Rules
- board readability is more important than decoration
- decorative elements should not eat into the board cells
- keep pixel density compatible with the dungeon zone
- no blurring, no mushy leaf clutter

## Deliverables
- board frame asset set
- assembled Unity screenshot
- close-up crops of corners and trims

## Stop
Stop for approval after this stage.

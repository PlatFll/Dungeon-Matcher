# Stage 1 — Forest structure foundation

## Objective
Build the **top battle background / enemy area background** for the Magical Forest zone.
This is the most important stage.

## Inputs
- `references/01_forest_mockup_reference.png`
- `references/02_current_dungeon_zone_reference.png`

## What to build
Create a modular forest top battle background that:
- uses the forest mockup as the visual inspiration
- matches the dungeon zone's production readability and simplicity
- gives enemies a clear, readable horizontal standing area
- feels magical and forest-themed without excessive clutter

## Required scene layers
1. **Far background**
   - forest depth
   - soft scenic read, not noisy
   - optional distant waterfall / bridge / stag / glow cues if kept subtle
2. **Midground combat backdrop**
   - trees, rocky edges, forest opening, shrine-like framing if useful
3. **Enemy ground strip**
   - flatter, readable battleground where enemies stand
   - should not become noisy or overly textured
4. **Top-side dressing anchors**
   - hanging lantern points / vine anchors / carved wood support context

## Simplification rule
This must be **cleaner and less dense than the forest mockup**.
Think “production-ready forest zone” rather than “splash art forest”.

## Preferred workflow
- Use PixelLab for concept-quality forest background chunks only if needed.
- Clean, reduce, and unify in LibreSprite.
- Build modularly, not as a one-off final painting.

## Deliverables
- background layer assets
- modular ground strip / battleground assets
- one Unity preview screenshot with the new forest top background assembled
- explanation of what was generated vs cleaned

## Stop
Stop for approval after this stage.

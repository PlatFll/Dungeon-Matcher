# Snowy Mountain Zone PixelLab Stage Pack

This pack is for **Astra** to rebuild the **snow mountain / frozen pass zone** in the same staged way used for the enchanted forest pack.

## Core intent
Build the zone by **describing the scene and each asset in text**, generating pieces in **PixelLab**, cleaning / palette-aligning them as needed, then assembling them in Unity.

Do **not** rely on attaching the target mockup and hoping PixelLab reproduces it. The mockup is an **approval target and composition guide**. The actual build should happen through **focused stage-by-stage text generation**.

## Use this pack in this order
1. `00_STARTER_PROMPT.md`
2. `01_SCOPE_AND_EXECUTION_RULES.md`
3. `02_ART_DIRECTION_SUMMARY.md`
4. `03_REFERENCE_USAGE_GUIDE.md`
5. `04_STAGE_INDEX.md`
6. Then execute the stage files one by one, stopping after each stage.

## Key rule
Astra may use **as many PixelLab generations as needed**. Assets may be **large**. The point is quality and focus, not minimizing generations.

# Reference Usage Guide

## Main target
Use `references/00_TARGET_SNOWY_MOUNTAIN_SCENE.png` as the **exact build target** for composition, materials, and major asset identity.

## Family-style references
Use the other reference images only to keep the zone in-family with the finished game:
- underwater = how a strong zone makeover fully commits to its theme
- forest = how natural materials frame the board and HUD cleanly
- ironvein cave = how a dark environment can still keep the board readable
- dungeon = how geometric stone structure can remain clear and restrained

## Old snow reference
Use `references/05_OLD_SNOW_ZONE_BEFORE_REWORK.png` only as a reminder of what the pre-rework zone looked like. Do not preserve its outdated, under-developed structure unless it still helps gameplay readability.

## Important note
Do not use the main target image as a crutch for copy-paste generation. Instead:
1. describe the asset in text
2. generate it in PixelLab
3. compare it against the target
4. refine until it matches the intended look

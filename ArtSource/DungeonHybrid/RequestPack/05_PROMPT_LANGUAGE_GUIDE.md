# PixelLab Prompt Language Guide

## Important rule
When using PixelLab, ask for ONE asset or ONE tightly related asset family at a time.
Do not ask it to solve the whole scene.

## Prompt structure
Every prompt should include:
1. asset type
2. intended game use
3. shape/silhouette goals
4. shading goals
5. detail goals
6. what to avoid
7. style anchors
8. output constraints

## Required style language
Use phrases like:
- native pixel art
- clean readable sprite
- crisp silhouette
- large readable shapes
- limited controlled shading
- avoid anti-aliased blur
- avoid smeared texture
- avoid noisy crack overload
- premium but readable dungeon pixel art
- consistent with a clean fantasy match-3 UI world

## Example negative language
- do not generate a full scene
- do not use soft blended shading
- do not over-detail the surface with too many cracks
- do not use semi-realistic painting
- do not create isometric perspective drift
- do not blur edges

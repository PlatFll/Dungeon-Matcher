STAGE 05 — ASSEMBLY AND VALIDATION

Goal:
Assemble the full zone using the approved asset library.

Instructions:
- Build the top HUD background from modular structural tiles first.
- Place the gate/arch set as the focal center piece.
- Add pillars/supports if approved.
- Add props on top afterward: torches, chains, banners, barrels, skulls, jars, debris.
- Build the portrait frame and board frame from modular frame pieces.
- Build the lower HUD frame from approved parts.
- Do not change gameplay systems. This is an art assembly and validation task.

Validation tasks:
1. Native-scale screenshot checks
2. Seam checks
3. Broken pixel checks
4. Frame join checks
5. Palette consistency review
6. Readability against Rattlebones and gems
7. “Too noisy / too blurry / too detailed” review

Approval rule:
An asset or assembled section should only be marked approved if it is at least a 90% style match for:
- shading discipline
- color harmony
- pixel cleanliness
- readability
- structural alignment

If it fails:
- regenerate or repair only the failing asset/section
- do not blow away the whole scene

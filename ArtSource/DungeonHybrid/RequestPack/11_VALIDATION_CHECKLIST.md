# Validation Checklist

Use this after every asset and after every assembled layout update.

## Pixel integrity
- [ ] no blur
- [ ] no accidental anti-aliasing
- [ ] no broken pixels
- [ ] no torn edges
- [ ] no muddy clusters

## Style match
- [ ] compatible with Rattlebones
- [ ] compatible with gem readability
- [ ] controlled shading
- [ ] large readable shapes
- [ ] detail supports readability rather than fighting it

## Structural quality
- [ ] tiles align cleanly
- [ ] seams are invisible or intentional
- [ ] modular parts fit together
- [ ] no missing chunks
- [ ] no warped perspective drift

## Scene quality
- [ ] top HUD reads clearly
- [ ] focal gate area is strong
- [ ] props add flavor without clutter
- [ ] portrait frame is distinct from surrounding background
- [ ] board frame feels premium and stable

## Acceptance rule
If any item fails, fix or regenerate that specific piece only.

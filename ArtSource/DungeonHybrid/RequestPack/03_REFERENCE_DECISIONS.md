# Reference Decisions

## Use the cleaner structural direction as the base
The base zone should use:
- simple side-view dungeon staging
- clean, readable wall bricks
- larger, less noisy floor/platform bricks
- a flatter readable battleground plane
- modular construction

## Match against Dungeon Matcher style anchors
Primary style anchors:
- Rattlebones
- gem set
- current clean UI language

## Style targets
- readable at native scale
- crisp and clean
- no blurred clusters
- no accidental anti-aliasing
- no muddy over-detail
- no random noisy cracking everywhere
- large readable shapes first, detail second

## What “match” means here
A good match does NOT mean copying every old pixel.
A good match DOES mean:
- same world/aesthetic family
- similar shading discipline
- similar color discipline
- compatible readability and contrast
- premium but clean pixel treatment

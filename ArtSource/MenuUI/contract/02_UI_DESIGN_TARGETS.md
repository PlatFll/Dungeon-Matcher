`/mnt/data/ghostwriter_images/generated/a_vertically_oriented_pixel_art_game_title_screen_5_batch_4.png`

### Core look
- Dark purple dungeon throne hall.
- Large, dramatic logo at the top.
- Rattlebones centered on a pedestal.
- Strong vertical composition.
- Chunky stone-and-metal menu buttons with purple jewel studs.
- Warm orange torchlight against cool purple dungeon stone.
- Royal skull motifs.
- The whole screen should feel polished, premium, readable, and iconic.

### Must-capture design features
- Large, bold, layered `DUNGEON MATCHER` logo.
- Purple jewel under / around logo centerpiece.
- Purple banners with skull-crown iconography.
- Strong throne-room symmetry.
- Big central PLAY button.
- Secondary menu buttons arranged below in a clean, symmetric grid.
- Distinct icon + text pairing per button.
- Purple carpet / royal path composition.
- Thick pixel stone frames with bright silver/gray tops and purple accent jewels.
- Crisp, blocky, readable pixel text.

### Buttons visible in target
- PLAY
- CHARACTERS

- settings / gear button

### Shared style extracted from this screen
This screen should define the global style for:

## B. Pause / Settings target
Reference image:
`/mnt/data/ghostwriter_images/generated/a_pixel_art_video_game_screenshot_dark_fantasy_du_6_batch_5.png`

### Core look
- Large centered overlay panel.
- Dimmed gameplay background.
- Big stone/metal settings frame with skull crest.
- Tidy settings rows.
- Distinct ON / OFF toggle styling.
- Large stacked action buttons.
- Color-coded emphasis for Resume and End Run.

### Must-capture design features
- Heavy stone frame with bright top edges and darker inner framing.
- Purple jewel corner details.
- Skull crest / skull plaque at top.
- Big centered SETTINGS title.
- Toggle rows with icons on the left, text in the middle, state/toggle on the right.
- Large Resume button in green.
- Neutral gray action buttons beneath.
- Strong red End Run button.
- High readability and strong pixel contrast.
- Background gameplay is visibly dimmed but still readable behind the overlay.

### Rows visible in target
- MUSIC — ON
- SFX — ON
- REDUCED MOTION — OFF
- VIBRATION — ON

### Action buttons visible in target
- RESUME
- SUSPEND TO MENU
- END RUN AND RETRY
- END RUN

### Shared style extracted from this screen
This screen should define the global style for:
- modal / popup frames
- settings-row modules
- on/off toggles
- confirmation / destructive button color language
- general gear/settings button language

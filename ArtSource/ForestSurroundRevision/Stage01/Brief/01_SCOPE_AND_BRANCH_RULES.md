# Scope and Branch Rules

## Branch name
Create a new branch using a name like:
`feature/forest-zone-side-surround-revision`

## Scope
This task is a **targeted revision**, not a full remake.

### In scope
- Left and right environmental surroundings around the board frame
- Lower left and lower right surroundings near the bottom HUD
- Supporting decorative asset passes for those areas
- Minor seam cleanup where revised areas meet preserved areas
- Subtle supporting animation candidates (wisps, swaying leaves, hanging vine tips) if useful, but still-art readability comes first

### Out of scope
- Full zone remake
- Replacing the top HUD layout
- Replacing the top battle background
- Replacing enemy placement
- Replacing the board frame dimensions or grid layout
- Changing the bottom HUD center layout or functional UI structure

## File safety
Do not destroy existing good work. Preserve current assets and scene state before revision. If creating variants, keep originals available for comparison.

## Review rule
No merge. Stop for review at the specified checkpoints.

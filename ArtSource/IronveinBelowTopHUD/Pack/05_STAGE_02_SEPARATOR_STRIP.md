# Stage 02 — Separator Strip / Upper Board Ledge

## Goal
Generate the horizontal structural strip between the top combat scene and the board.

## Visual target
This strip should feel like a heavy reinforced mining ledge:
- timber beam base
- forged metal braces
- bolts / rivets
- amber crystal accent nodes set into diamond or square plates
- chunky readable construction
- clean symmetry across the board width

## PixelLab generation approach
Generate this as small modular pieces:
1. center beam section
2. repeatable beam section
3. decorative crystal node section
4. transition/endcap section

## Prompt direction for PixelLab
Create pixel art UI structural beam pieces for a dwarven mine themed match-3 interface. Use dark wood, forged steel brackets, rivets, and glowing amber crystal accents. The pieces should feel sturdy, readable, and game-ready, with crisp pixel-art shading and clean silhouettes. Avoid blur, avoid excessive micro-detail, and make the beam feel like part of a mining machine.

## Requirements
- must connect cleanly to the board frame below
- should visually bridge from the top HUD into the new board system
- no loose floating ornaments

## Deliverable
Import the best approved pieces, assemble the separator strip, and show the rebuilt strip in-scene.

## Stop
Stop for review after Stage 02.

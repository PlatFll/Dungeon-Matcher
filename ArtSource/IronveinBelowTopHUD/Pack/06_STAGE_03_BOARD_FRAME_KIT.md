# Stage 03 — Board Frame Kit

## Goal
Generate the full main board frame kit for the Ironvein lower-half.

## Board frame identity
The board frame should be a hybrid of:
- timber mine supports
- riveted iron plates
- amber crystal set pieces
- industrial dwarven craftsmanship

## Required pieces
- top board rail
- bottom board rail
- left board vertical rail
- right board vertical rail
- four corner modules
- repeatable connector plates / braces
- amber crystal inset plates for accent nodes

## Prompt direction for PixelLab
Create crisp pixel-art modular board-frame pieces for a fantasy dwarven excavation match-3 game UI. Materials: dark timber beams, forged iron straps, riveted metal brackets, and glowing amber-orange crystal inserts. The frame must be sturdy, symmetrical, and highly readable, with a premium fantasy-industrial look. Keep the shading clean and controlled, not blurry, not painterly.

## Composition guidance
- the frame should feel more premium than a plain rectangle
- thickness should support the drill modules later
- preserve gameplay readability; do not visually crowd the gem board

## Deliverable
Assemble a clean board frame without drills yet and validate spacing / readability in-scene.

## Stop
Stop for review after Stage 03.
